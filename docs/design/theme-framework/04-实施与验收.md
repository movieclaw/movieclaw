## 3. 风险与对策

| 风险 | 对策 |
| --- | --- |
| globals.css 拆 tokens.css 后 Tailwind v4 编译顺序变化导致覆盖失效 | `@import "../themes/netflix/tokens.css"` 放在基础组**之后**；迁移后首验即跑银玻璃零变化对比（若 Netflix 覆盖失压会立刻显形） |
| 坑位迁移时 props 签名走样（13 处消费点） | 迁移是"移动 + 换解析来源"，不改组件内部；code review 对照 02 文档 §4 映射表逐行核 |
| 防闪烁脚本序列化引入引号转义问题 | 服务端 `JSON.stringify` 产出 + 与现状脚本逐字符 diff 校验（netflix 命中路径的输出必须等价） |
| vendor 反转漏改某个调用点 | `glassEnabled` 默认 true = 现状行为，漏改不产生可见变化；grep `useTheme` 在 vendor 目录必须为 0 兜底 |
| 迁移期间 `components/netflix/` 半搬状态 | 提交 ③ 一次搬完并删除旧目录，不设过渡期；commit 内自含 |
| 与并行前端 WIP 冲突（工作区纪律：绝无 stash） | 每个 commit 前后 `git status` 确认干净；本设计落地前先合入或在干净基线上开工 |
