MCP 是 AI 客户端连接外部工具的通用协议。建一个端点，勾选要开放的服务， Claude Code、Cursor 等客户端填上地址和令牌就能直接查库存、下片、管订阅。

每个端点的工具目录相互独立——给不同用途建不同端点，互不干扰。

它和「设备」页的令牌有什么区别？
设备令牌 = 一台机器的完全权限（给 mclaw 命令行用）；MCP 端点 = 一组你自己挑的工具， 可以只开放订阅与搜索、不碰媒体库。两者独立签发、独立吊销。

列表是这一页的主界面：一端点一卡，卡上直接能启停；徽标标出工具模式（展开/折叠）；「最近调用」是判断能不能删的依据。

关（折叠）：一个服务一个工具（subscriptions），参数是「命令名 + 参数对象」，工具少得多
两种形态都能用，看客户端脾气：有的客户端擅长在大工具集里检索，有的会把工具全量塞进系统提示词。 展开模式下每个工具带类型化参数和 readOnly / destructive 注解，支持注解的客户端会在执行 破坏性工具前向人确认；折叠模式工具少、占的上下文小。工具超过 30 个时下面会给出建议， 但不拦你——要一个全能端点也随你。

⚠️

确认弹窗

停用 / 轮换令牌 / 删除

停用「家庭影音助理」？

停用后该地址立即返回 404，已接入的客户端会连不上，但配置和令牌都保留，随时可以再启用。

轮换令牌？

会生成一枚新令牌，旧令牌立即失效。你需要在所有已接入的客户端里更新配置， 否则它们会开始报 401。新令牌同样只显示一次。

删除「运维调试」？

端点地址与令牌一并作废，不可恢复。该端点最近一次调用是从未——如果还有客户端在用， 删除后它们会立刻失败。

总开关关闭态：不隐藏已有端点（否则用户会以为配置丢了），而是整体置灰并说清后果。
