MCP 是 AI 客户端连接外部工具的通用协议。建一个端点，勾选要开放的服务， Claude Code、Cursor 等客户端填上地址和令牌就能直接查库存、下片、管订阅。

每个端点的工具目录相互独立——给不同用途建不同端点，互不干扰。

它和「设备」页的令牌有什么区别？
设备令牌 = 一台机器的完全权限（给 mclaw 命令行用）；MCP 端点 = 一组精选工具 + 一档执行策略， 可以只读、可以只开放订阅与搜索。两者独立签发、独立吊销。

列表是这一页的主界面：一端点一卡，卡上直接能启停；危险档位常驻红标；「最近调用」是判断能不能删的依据。

⚠️

确认弹窗

停用 / 轮换 / 删除 / 选择完全档

停用「家庭影音助理」？

停用后该地址立即返回 404，已接入的客户端会连不上，但配置和令牌都保留，随时可以再启用。

轮换令牌？

会生成一枚新令牌，旧令牌立即失效。你需要在所有已接入的客户端里更新配置， 否则它们会开始报 401。新令牌同样只显示一次。

删除「运维调试」？

端点地址与令牌一并作废，不可恢复。该端点最近一次调用是从未——如果还有客户端在用， 删除后它们会立刻失败。

确认使用「完全」策略？

这个端点将能执行全部命令，包括 library items delete—— 它会删除磁盘上的媒体文件，且不经过任何人工确认。只在你完全信任接入方时使用。

总开关关闭态：不隐藏已有端点（否则用户会以为配置丢了），而是整体置灰并说清后果。
