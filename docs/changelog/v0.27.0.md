## movieclaw v0.27.0

这一版的重点在**第三方播放器**：Infuse / VidHub 等 Jellyfin 客户端调低画质时，
服务端终于会按要求转码，Safari 直出 HEVC MP4 也不再「先失败再降级」。Web 端银玻璃
主题的手机导航换成了 iOS 26 液态玻璃风格的悬浮底栏。另外，一个文件夹里放多部电影
的合集现在能逐部入库了。

> ⚠️ **本版需要更新 Docker 镜像**（runtime 16 → 17）：上游 sqlmodel 0.0.45 起会拒绝
> 写入不带时区的时间，新构建的镜像若装上它，所有写库操作都会失败。本版把依赖锁在
> `<0.0.45`，只有新镜像带着这个修正。请执行 `docker pull movieclaw/movieclaw:latest`
> 后重建容器；旧镜像在「设置 → 更新与维护」里会看到「需升级 Docker 镜像」的提示。

### 新功能

#### Jellyfin 客户端调低画质时真的会转码

以前 Infuse / VidHub 这类客户端不管选什么清晰度，服务端一律直连原文件，限码率等于
没限。现在客户端限了码率、或者明确不要直连时，服务端会按要求转成 H.264 HLS，档位
规则与网页播放器一致：

- 按客户端申报的格式出分片：只收 TS 容器的客户端（如 Infuse）拿到 MPEG-TS，音轨超出
  它支持的范围时转成 AAC 并压到它能播的声道数。
- 转码时内封文本字幕抽出来外挂投递；图形字幕在转码时不再出现在可选列表里。
- 切换清晰度时旧转码会话会被准确停掉，播放进度上报会让转码会话保持存活。
- 以下情况仍然直连：没有可用的转码能力（无显卡且未开软件转码、HDR 片没有显卡）、
  strm 文件、原盘。

> 已知限制：Infuse 播放原盘时调低画质大概率仍会失败；VidHub 尚未真机验证。

#### 银玻璃主题手机端：液态玻璃悬浮底栏

手机上（窄于 768px）的导航从「顶栏 ☰ → 抽屉侧栏」改成悬浮在底部的玻璃胶囊栏：
发现 / 媒体库 / 订阅 / 活动（仅管理员，有新动态时带小圆点）+ 尾端搜索按钮。设置、
最近会话、切换账号收进右上角头像弹出的「更多」面板；新会话改为顶栏撰写键 + 底部
撰写面板。选中胶囊可以按住拖动切换，滚动时底栏会贴底收缩。

同时发现页改为沉浸式 Hero（「电影 / 剧集」切换挪到底部），媒体库页的操作按钮收进
顶栏，会话页加了返回键，启动页与 iOS 启动图保持一致并淡出，弹出软键盘时布局不再
错位。Netflix 主题不受影响。

#### 一个文件夹里的电影合集逐部入库

以前一个文件夹里放了多部电影，只会取最大的文件入库、其余静默丢弃。现在会逐文件
识别、按作品分别入库，行为与把这个目录放进媒体库扫描一致（花絮、预告仍不入库）。
识别不出的文件在导入清单里各自有一个「认领」按钮。

升级后，旧版结论里写着「已取最大文件为正片，忽略其余」的记录会**自动重跑一次**，
把当时漏掉的影片补回来（发生过搬运的中转目录除外）。文件名里没有片名的合集
（如 `01.mkv`、`02.mkv`）仍会被当成同一部，需要手动认领。

#### 媒体库自定义封面

编辑媒体库的弹窗里多了「封面」区域：上传、换一张、恢复自动拼贴，上传即生效。
控制台首页、管理页和 Jellyfin 客户端都会显示这张封面，空库也能显示。建议比例
21:10（如 1260×600），图片不会被裁剪；服务端会统一压缩并去掉 EXIF（包括 GPS 位置）。

#### 飞书推送

消息推送新增飞书群机器人：粘贴群机器人的 Webhook 地址即可绑定。

### 改进

- **Safari / iOS 直接播放 HEVC MP4**：大部分 WEB-DL 的 HEVC MP4 带的是 Safari 不认的
  `hev1` 标签，以前要先失败一次再降级，起播多等 6～35 秒。现在传输时把标签改成
  `hvc1`，不转码、不改磁盘上的原文件。网页播放器与走 AVPlayer 的 Jellyfin 客户端都受益。
- **TMDB 镜像地址只填域名也能用**：漏写 `/3`、`/t/p` 这类官方后缀时会自动补齐；
  自己写了路径（如自建反代的 `/tmdb` 前缀）则原样保留。补齐后的结果会回显在输入框里。
- **异常退出告警可以「知道了」**：「设置 → 更新与维护」里的异常退出横幅可以手动消除，
  下次再异常退出会重新提醒。
- **Netflix 主题视觉统一**：页面边距、返回按钮、提示色、设置页布局全站一致。

### 修复

- **大文件 AI 字幕预检不再报 `Load failed`**：十几 GB 的 MKV 预检要通读整个文件，
  iPhone Safari 约 60 秒就断开连接。现在预检立即返回、抽取转到后台，关掉对话框也会
  继续完成；播放器与字幕生成共用同一份抽取结果，不再把同一个文件读两遍。
- **「交给 Agent 处理」会带上你选的语言**：以前目标语言、双语、参考字幕都没带过去，
  Agent 只能按默认参数重跑出单语字幕。
- **Infuse 限码率播放 404**：HLS 分片地址拼错的问题已修复。
- **详情页背景**：推镜动画约 1 秒处的叠影、换高清图时的黑闪都已修好；发现页 Hero
  第一帧不再是静止的。
- **Windows 部署图片 404**：本地图片资产路径统一使用正斜杠。
- 窄屏下详情页标记按钮的提示不再自己弹出挡住主按钮；手机端媒体库筛选抽屉可以滚动；
  条目详情页右上角菜单丢失的问题已修复。
