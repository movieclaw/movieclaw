## movieclaw v0.20.0

这一版的主线是 **AI 助手（Agent）能力大版本**：发图给它看、控制它想多深、教它新技能、
输入框全面升级，以及一轮针对「跑到一半出事」的运行时稳定性加固。另有两条洗版与
媒体库的重要修复。

> ✅ **本版无需更新 Docker 镜像**：运行时依赖没有变化（runtime 仍为 13），
> 在「设置 → 更新与维护」一键更新即可。

---

### 新功能

#### AI 助手支持图片输入

- 网页端对话框可以直接**上传图片**（含预览与气泡内渲染），让助手看海报、看截图、
  看报错弹窗。
- 微信 / Telegram 等 IM 通道的入站图片同样可用。
- 图片按引用存储、24 小时自动清理暂存，不会撑爆对话记录。

#### 思维链深浅可控

- 对话输入框新增**思考档位选择器**：同一个模型可以按需选择「想多深」，档位菜单由
  服务端按模型的实际能力自动推导（effort / budget / 开关三种方言统一适配）。
- 选定的档位随对话持久化，续聊自动沿用。

#### 技能机制：教助手一套自己的流程

- 助手启动时会看到可用技能清单，按需渐进加载；技能分**内置**与**用户自定义**两层，
  同名时用户的覆盖内置的。
- 内置 `skill-creator` 技能：直接让助手「帮我创建一个技能」，产物落在用户目录。
- 对话里可用 `/skill:名字` 显式调用，气泡中以 chip 标识。

#### 对话输入框升级富文本

- 斜杠快捷选技能、技能名渲染为原子 chip、布局重构，输入体验对齐主流 AI 产品；
  底层序列化契约不变，历史对话不受影响。

### 改进

- **AI 助手运行时稳定性加固**：硬崩（如容器被强杀）后会话不再出现被供应商永久拒绝
  （400）的死局，重启自动自愈；点「停止」后半截输出会明确标记「已停止/已中断」而
  不是凭空消失；助手启动的子进程（bash / mclaw）超时或取消时整组回收，不再留孤儿
  进程。以上均经混沌测试（kill -9 → 重启 → 续聊）与浏览器级端到端验收。
- **供应商模型目录刷新**（官方文档核实于 2026-09-01）：Kimi 补 k2.6 思考声明与 k3
  多模态；DeepSeek 补三档推理强度与多模态实验模型；GLM 新增 glm-5.3 / 5.3-flash；
  百炼 Qwen 旗舰推进到 3.8 系；OpenAI 补全推理强度档位。
  ⚠️ **Kimi k2.5 已被官方下线并从目录移除**：已配置它为默认模型的用户现有配置
  继续可用，但重新保存供应商配置时需改选 k2.6 / k3。
- **ffprobe 探测失败会自动重试了**：网络挂载（SMB/NFS）抖动导致的探测失败，此前
  只能靠手动扫描补救，现在按退避间隔（1 小时起翻倍、封顶 24 小时）自动重试，6 小时
  定期对账每轮限量自愈一批；真损坏的文件也有了失败记忆，不再每轮扫描都白等 30 秒
  超时。
- **README 改为英文默认**，中文版移至 `README.zh-CN.md`，顶部一键切换；新增
  「在别的机器上操控它」章节介绍 mclaw 命令行入口。

### 修复

- **蓝光原盘不再被 Remux「洗版」洗掉**（issue #163）：片源阶梯此前最高只到
  Remux，原盘反而排在其下——同分辨率下一个 Remux 候选会被判成升级，叠加默认
  不保留旧文件，原盘就被送进回收站。现在片源阶梯补上顶档「原盘」，由目录结构证据
  （BDMV / VIDEO_TS / ISO）判定，种子名里的字样冒充不了它；配了片源白名单时原盘
  同样高于一切。存量数据自动回填，升级后无需任何操作。
  已知副作用：整理命名模板用了 `{media_source}` 且库里有 ISO 的用户，下次整理该段
  会渲染成 `Disc`（原盘目录本身不受影响，整理对它整体跳过）。
- **订阅追踪中（尚未入库）的条目可以改元数据和选图了**（issue #278）：这类条目在
  媒体库页带海报展示，但重刮、候选图、选图、刮削归属四个入口此前都被「有库存文件」
  的前置条件挡住（404），整库刷新也会静默跳过它们。现在四个入口按刮削归属库放行，
  整库刷新把它们并入目标清单。
- 修复一批 AI 助手细节问题：取消看门狗误杀慢收尾、附件校验顺序、IM 通道收尾文案、
  技能名插入缺空格、无效技能 chip 冒充等。
