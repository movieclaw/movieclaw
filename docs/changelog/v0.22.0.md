## movieclaw v0.22.0

距上一版两周，这是目前改动最大的一版：媒体库多了**图片**类型，影片可以**分享给站外的人看**，
视频有了**章节与场景图**，每个库都有了**「谁能浏览」**，一个浏览器能同时登录**多个账号**，
AI 可以**同时接入多家供应商**，活动页长出了完整的**观看统计**，媒体库的管理面从浏览面独立出来
并带上了**回收站**，设置里新增**缓存管理**。

> ✅ **本版无需更新 Docker 镜像**：运行时依赖没有变化（runtime 仍为 13），
> 在「设置 → 更新与维护」一键更新即可。

---

### 新功能

#### 媒体库新增「图片」类型

- 建库时可以选「图片」：扫描目录里的所有照片，进库后是**按月分组的瀑布流相册墙**，
  点开是全屏灯箱。密度三档（页头「⋯」菜单里切），墙右缘有 Google Photos 式的
  悬浮时间刻度，滚动时才现形。
- 灯箱里滚轮 / 双击缩放、拖拽平移、方向键与触屏翻页，翻到末尾自动加载下一页；
  可看拍摄信息、下载原图；缩放交给捏合与双击，缩放按钮只留给有鼠标的设备。
- **四级渐进式加载**，4000×3000 的相机直出照片也不会等白屏：扫描一结束布局就已定好
  （用入账时探到的原图尺寸定比例，永不跳动）→ 随列表下发的 16px 微缩占位图（约 400 字节）
  → 480px 的 WebP 瓦片 → 灯箱里先给约为原图 8% 的屏幕适配图，放大了才拉原图。
- 拍摄时间取自 EXIF，照片方向标签会被纠正；图片库默认不上首页，也不会出现在
  Jellyfin 客户端里。
- 一期暂不支持 HEIC/HEIF（需要新依赖）、相册层级、灯箱内删除照片。

#### 电影 / 剧集 / 其他库也能当图床浏览

- 海报墙右上角多了一个切换键，点一下换成与相册墙一样的瀑布流：每部作品一段，
  图来自海报、横幅剧照、分集剧照与章节场景图，在灯箱里可以**从那一帧起播**或进详情页。
- 瀑布流与海报墙上的作品带收藏标识，图廊灯箱里可以直接点心收藏。

#### 视频章节与场景图

- 详情页多了一条**场景横排**：内嵌章节有就用内嵌的，没有就按时长合成 3～12 段。
  点一张图从那一帧开始播——图上记的是那一帧的真实时间，不会像抽帧缩略图那样漂几秒；
  带「上次看到这里」角标，剧集随选中的分集切换。
- 建库 / 编辑库里有「生成章节」开关，扫描结束自动排队；也可以在库菜单或条目菜单里
  手动「生成章节」，是否连已有的一起重抓在确认弹窗里勾。管理页与库卡片能看到
  **排队与进度**（「正在生成章节 35%」），跑着的时候菜单项置灰。
- **Jellyfin 客户端（Infuse 等）也能看到章节**：`Chapters` 字段与章节图接口都已输出。
- 「重新生成缩略图」改名「重新生成封面」——封面是主图，和场景图是两件事。

#### 影片分享：一条链接发给没有账号的人

- 超管在条目详情页 ⋯ 菜单点「分享…」，得到一条 `/s/{slug}` 链接。有效期 1 / 3 / 7 / 30 天
  （默认 7 天，没有「永久」），可开密码（自动生成 6 位访问码，可改），
  「链接和密码」一键复制。一部影片同一时间只有一条有效分享，再点就是展示已有的那条。
- 拿到链接的人**不用登录**就能看这一部影片（剧集就是整部剧集）：信息、音轨字幕、
  场景章节、演职员、相关链接都能看，可以选季集、直接播放，播放器是同一个。
  有密码时先只见密码卡片，**不露片名和海报**。
- 访客的进度只记在访客自己的浏览器里，不写你的观看记录；活动页把访客显示为
  「分享访客」，可以随时结束其播放。
- 媒体库管理页新增「分享」标签，列出全部有效分享并可取消——**取消后正在播的连接
  下一秒就断**，不是等缓存过期。

#### 收藏 / 已看：网页端和播放器同一份数据

- 详情页播放键右侧多了**心**（收藏整部电影 / 整部剧）与**对勾**（标记当前单元已看 / 未看）。
  在网页上点的心，Infuse 里立刻能看到；反过来也一样——两边落的是同一张表。
- 媒体库首页在「最近观看」下新增「**我的收藏**」横滚行，「查看全部」进 `/library/favorites`。
- 标记已看会清零续播点，整剧标已看会级联到每一集。
- 分集卡上暂时还没有逐集的心 / 对勾。

#### 多账号切换：一个浏览器同时登录多个账号

- 左下角用户菜单新增「切换账号」：账号列表里点一下即切，**不用再输密码**；
  行尾 × 把某个账号从本浏览器移除，弹窗里也能「添加账号」和「退出全部账号」。
- 「退出登录」现在只退当前账号，浏览器里还有别的账号会自动切过去。
- 最多存 5 个账号，超了淘汰最久未用的。凭证仍是 HttpOnly，超管改密、成员停用与改密
  这些失效语义对所有已存账号自动生效。

#### AI：多供应商接入、AI 设定分离、对话框选模型

- **供应商不再是单例**：可以同时接入多家，接入一家就能用它目录里的全部模型。
  设置页拆成「模型接入」（实例列表，可编辑 / 重测 / 删除）与「AI 设定」
  （智能体、字幕处理各自选默认模型）。
- **对话框可以选模型**：输入框上方新增「模型」菜单，与思维链档位并排；
  选择记在本浏览器，作为下次新任务的起点（会话自己的档位仍跟着会话走）。
- **思维链强度改成横向滑杆**：整条轨道可点可拖，松手吸附最近刻度，左右键也能切；
  只有开关的模型（kimi-k2.6、glm-5.x 一类）改用「开启（模型默认）/ 关闭」两项列表，
  并写清各自的含义，不再是看不懂的「默认」。
- 同一个模型 id 出现在多家时，展示为「模型id（实例名）」、引用为「实例名/模型id」精确路由，
  不会串到另一家去。

#### 媒体库「可见范围」：每个库都能指定谁能浏览

- 建库 / 编辑库新增「可见范围」：所有成员 / 指定成员（可搜索多选，「超管（我自己）」是
  第一个选项）。**超管也受约束**——没勾自己的库在首页是带锁的「仅管理」卡片，
  想看点一下「把我加入可见范围」。
- 管理权与浏览权分开：范围外的库仍可管理配置，但海报墙、封面、条目、播放一律不可见；
  图片资产接口按条目所属库校验，猜 id 也取不到范围外的海报；Jellyfin 客户端的
  Views 与可访问目录同样按范围投影。
- 成员管理页与库设置页写同一份数据：「全部库」只自动含「所有成员」的库，
  指定成员的库单独勾选，保存时不再清掉这些显式授权。
- 媒体库列表默认只列你能浏览的库，CLI / AI 助手与网页首页口径一致；人物页也补上了过滤。

#### 观看记录可以清除

- 三处入口：条目详情页、单库页 ⋯ 菜单、设置 → 个人信息「观看历史」；
  首页「最近观看」的 ⋯ 菜单里也能清空。可按条目 / 按库 / 全部清。

#### 活动页：完整的观看视角

- 观看视角分成三个切片：**正在播放 / 最近播放 / 观看统计**。
- **网页端播放现在也出现在「正在播放」里**了（此前只有 Jellyfin 客户端可见），
  网页与 Jellyfin 走同一套上报，暂停 / 恢复即时上报不等心跳。
- **「结束播放」**：可以只掐断某台设备本次播放而不动它的凭据；设备进入 60 秒拒绝窗口，
  网页播放器会收到信号并说明原因，重新开始播放即解除。
- **最近播放**：按天分组、滚动到底自动续载，每行带看到百分比。
- **观看统计**：四张指标卡（本期值 + 环比 + 「上期 x」参照）、按天柱状主图（叠上一周期虚线）、
  Netflix「TOP 3」式的本期最受欢迎（口径是**看过的成员最多**，与「看得最多」是两个问题）、
  按成员 / 客户端 / 作品 / 播放方式四块分解面板（点成员名可整片钻取）、观看时段热力图。
  周期与成员在工具栏里选。
- **「全部 / 我的浏览范围」口径切换**：默认按你的浏览范围折叠，范围外的记录只报数量、
  不露片名；切到「全部」时范围外条目标「仅管理」且不给详情链接。
- 每个区域都有说清「本来会有什么、为什么没有、接下来能做什么」的空状态，
  读取中是与最终布局同形的骨架，内容到达时不跳动。

#### 媒体库：预览与管理分离

- 首页只做浏览入口，管理搬到独立的 `/library/manage`；「管理媒体库」「创建媒体库」
  移到页头标题右侧。
- 管理页**页头先回答「有没有事要我管」**：副标题是活的摘要，两枚可点胶囊
  「N 个在跑任务」「N 个库有待处理文件」即筛选，都为 0 时写「一切正常」。
- 列表改四区（库 / 库存 / 状态 / 操作）：根目录并入库名下的小字，可见范围只在偏离默认时
  挂胶囊，配置备注只写偏离默认的，空闲的库不写状态词。待识别 / 缺失是带色胶囊，
  点它直达待处理清单。
- 开始扫描有 toast 回执，空闲行写出最近一次扫描的结论（新增 N 个 / 标记缺失 M / 无新文件）——
  秒级完成的扫描不再像"没点上"。
- 库相关任务一有变化就立即重拉，不用等最长 30 秒的轮询周期。

#### 管理页新增「回收站」标签

- 洗版换下来的待回收文件此前只能一个条目一个条目地翻。现在跨库集中管理：
  常驻摘要行（`N 个文件 · M 个条目 · 总大小 · K 个将在 24 小时内自动清理`）、
  按片名 / 剧名 / 文件名搜索、库与原因胶囊分面计数。
- **一个条目一行**（剧集不管多少集都是一行，点箭头展开到每集），一格两行显示
  种子名与解析出的品质（档位 · 大小 · 编码 · 音轨 · 制作组），点种子名弹出完整存放路径。
- 倒计时就放在恢复 / 清理按钮正上方，24 小时内是警示色；勾选后底部浮出批量条，
  清理走确认弹窗（写明文件数、涉及条目、释放空间），恢复不弹确认。

#### 设置 → 更新与维护新增「缓存管理」

- `data/` 下的缓存此前没有上限也没有入口，盘满的第一个症状往往是转码写不进去。
  现在有**磁盘概览**（应用数据 / 可回收缓存 / 其他占用 / 剩余的分段条）与
  **逐目录的占用与清理**：每行「名称 + 一句话用途 | 占用 | 动作」，动作分
  「清理孤儿」（媒体库里已不存在的条目，无损）和「全部清空」（重建代价高的标红），
  都要行内二次确认。
- 清理只删登记目录内的直接子项，从不删目录本身，并会跳过正在转码的会话目录、
  运行中字幕任务的断点与生成中的临时文件。
- 用户资产与系统状态只展示占用、不提供删除；发现登记表之外的目录会明确提示。
- 「维护」标签并入「版本与更新」，缓存统计改为点开才算，不再一进页面就扫盘。

#### 下载器：路径可达性体检与故障归组

- 「测试连接」从「API 通」升级为「**API 通且路径可达**」：逐条路径映射做体检并留档。
- 落点故障按根因归组、换源刹车：一个挂载故障不再表现为十几条「下载完成但无法入库」，
  修好之前也不让自动换源继续烧流量。
- 待处理事项新增「**交给 AI 分析**」：后端按事项类型组装诊断工单（发生了什么 /
  系统已判定什么 / 已自动做过什么 / 你能做什么），点一下直接起会话。

#### 长任务断点续传

- 「生成章节」跑到一半重启（含应用内更新）不再从头重跑：勾了「已有的也重新生成」时
  按检查点跳过已处理的文件，进度也改成整轮累计口径——不会再从 400/1000 变回 0/600。
- 扫描重启后，上一轮识别出来却还没补上图的条目会被这一轮接着补，不用手动刷新元数据。
- 条目菜单的「重新生成章节」改成持久化任务：重启不丢、任务中心看得到、CLI 可以 `--wait`。

### 改进

- **剧集分集缺 TMDB 剧照时从视频抓帧补图**，TMDB 有图时始终优先用 TMDB 的。
- **海报不再被裁切**：派生图改为等比缩放装进外接框。其他库 16:9 的抓帧封面此前会被裁成
  2:3 竖条再被前端二次裁切，只剩画面正中一小块；现在横版封面按真实比例居中显示、
  用模糊铺底填满卡片。
- **其他库的本地美术图规则收成一份**（照抄 Jellyfin 的定位规则）：`<文件名>.jpg` /
  `<文件名>-poster` 精确匹配优先，目录级 `poster.jpg` 只在目录里的视频全归这个条目时才认，
  混放目录不再串图；`-fanart` 入账为背景图。只被授权「其他」库的成员在 VidHub 上
  此前看到 0 部电影，现在并入电影计数。
- 条目详情页的横排统一叫「**章节**」，无名章节叫「第 N 章」，不再混用「场景」「片段」。
- 灯箱交互全站统一（图片库、图廊、条目详情页、分享页共用一套）：去掉两侧箭头改为
  拖拽 / 滑动翻页，控件闲置 3 秒自动收起。
- 设置页里清理与重启的二次确认改用全站统一的确认弹窗。
- 图片的等待态与预加载提前量一并收紧，瀑布流去掉常驻角标、收紧间距、分组可关。
- 灯箱的缩放控件在悬停时显示当前比例，手势缩放能力改为自动判定；iOS 上下载原图
  改走系统分享面板（Safari 里直接点下载会打不开）。

### 修复

- **服务重启后 Infuse 正在播放的会话不再从活动页消失**：Infuse 这类播放器正常播放时不发心跳，
  重启后要等用户暂停再播才会重新出现；现在按取流证据重建会话。
- **活动页「最近播放」偶尔打开特别卡**。
- **手机上输入法收起后视口占位不再残留**，界面不会一直矮一截。
- **未识别条目的长文件名标题不再把整页横向撑开**（`Some.Movie.2023.2160p.BluRay…`
  整串没有空格，此前在手机上能把页面拖出去 1300 多像素）。
- 活动页观看统计的筛选行、对话框的模型 / 思维链弹层，在窄屏上都不再伸出屏幕右缘。
- 手机上点「切换账号」会先收起抽屉侧栏，弹窗不再被抽屉盖住。
- 手机上图片灯箱看不到底部缩略条。
- 分享页自己做滚动容器，手机上不再是死板的一屏。
- **订阅链路体检不再对本地内容库误报**：新建相册 / 其他库后概览页会亮出「下载器的路径映射
  没有覆盖媒体库目录」的红项，但这类库根本不是订阅目标，是一条永远修不掉也不需要修的红项。
- 超管在活动页「全部」口径下，范围外记录的海报此前一直 404 空着。

### 内部

- 基线 `spec.json` 改为构建产物不再入库，根治并行 PR 在这个 600KB 单行生成物上的必然冲突；
  镜像、发版脚本与 CI 本来就都是现场重导。
- 新增 `data/` 目录登记表（`services/storage/registry.py`）与三道守卫：业务新增落盘产物
  必须登记，CI 会拦下漏登记的 PR。
