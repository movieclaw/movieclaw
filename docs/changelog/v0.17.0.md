## movieclaw v0.17.0

这一版有两条主线。一是**「任务中心」重构为「活动」**：侧栏入口改名、路由从 `/tasks` 换到
`/activity`，页面一级不再按任务状态切，而是按领域分「观看 / 任务」——「观看」是全新的实时
视角，家里谁在播、播到哪、走的本地直连还是网盘直链、哪台设备在下载，一屏看全，可疑设备
还能就地注销。二是**修掉了一个会把整季剧集挂错目录的入库 bug**（issue #185）：像
`E01..E36` 这种只有集号、没有季号的整包，此前会散进 TMDB 里根本不存在的季目录。

> 本版**不需要更新 Docker 镜像**（runtime 仍为 8），在「设置 → 应用」一键更新即可。

### 新功能

- **活动页「观看」视角**：新增实时播放活动视图，展示
  - **正在播放**：海报、剧集、播放进度与暂停态、播放设备与归属成员、当前取流速率
    （网盘直链会明确标注，本地无流量时显示「本地直连」），海报和标题都能点进媒体详情页
  - **正在下载**：播放器的离线缓存下载独立成区，带真实进度条（断点续传从文件中段开始
    也能算准），同一文件的多条连接会聚合成一行，没有下载时该分区不渲染
  - **最近观看**：全体成员的观看时间线，带小海报
  - 数据全在内存里，不落库、无迁移；5 分钟没有上报且没有活跃取流的会话自动消失
- **注销可疑设备**：播放/下载卡右上角菜单新增「注销设备」（管理员专属）。注销会立刻
  吊销该设备的长期访问令牌、掐断正在进行的取流、并从实时视图中移除。观看进度按成员保存，
  注销不会丢进度。
  *已知限制*：这条路径只能处置**当前正在播放或下载**的设备，不在活动页出现的旧设备暂时
  还处置不了，需要后续独立的设备管理入口。
- **侧栏实时角标**：有播放或下载正在进行时，侧栏「活动」旁会亮起实时圆点；有失败或阻塞的
  任务时改亮警示角标，点击直接深链到任务视角的「需要处理」。

### 改进

- **活动页导航**：一级用「观看 / 任务」分段控件（与发现页 TMDB/豆瓣 同款），二级才是任务
  自己的四个状态。旧地址 `/tasks` 永久重定向到 `/activity` 并透传查询参数，已有书签和
  深链（如 `?view=active`）迁移后原样可用
- **移动端排版**：活动页视角切换器挂进全局顶栏（不再摞成两排 header）；播放状态徽标在窄屏
  收敛为彩色圆点（读屏用户仍能听到完整状态）；进度条改为贴卡片底边的全宽细条
- **刷流页面窄屏可读性**：做种头部的「展开」按钮不再被拆到第三行；单行去掉恒为空的下行
  速度列、数字列改为按比例缩放，360px 宽屏也不折行；分组汇总在窄屏排成 2×2 网格，
  「已下载」不会孤零零落到第三行；上行/下行的排列顺序在单行与汇总处统一
- **任务中心顶部的运行状态条已移除**：正常时是纯噪音，异常时的信息量不如下方会指名道姓的
  来源告警；同步中的反馈由标签栏右侧承担，不丢信息
- 侧栏「活动」改用脉冲图标，时钟归还给「最近会话」，同一列不再出现两个相同字形；
  呼吸圆点动画尊重系统「减少动态效果」偏好

### 修复

- **裸 `E` 命名的整季包不再挂错目录（issue #185）**：一个 36 集单季包若全部命名为
  `E01..E36`（没有 `S` 季号），此前逐文件推断会解出 25 个互不相同的季号，其中一批是
  「季号 = 集号」的幻觉（`E10` → `S10E10`），整包散进不存在的季目录，其余报解析失败；
  同一批文件在不同 NER 模型版本上错得还不一样，这正是「两次入库行为不一致」的原因。

  现在季集号改为**批次仲裁**：同一个包的季号必然相同，先用确定性规则（发布组明写的
  `SxxEyy`、目录里的季信息、TMDB 台账）定季，模型排在证据链最后、永远不能单独决定季号；
  推断出的季号还要经过「该季在 TMDB 是否存在」的守卫，被否决且台账只有一个正片季时改判
  到该季，实在定不下来就挂起等人工，而不是猜一个落盘。真实数据评测：6644 个正常命名文件
  结论零变化（无回归），剥掉季证据的单季条目从 0% 提升到 99.8% 且零错放，issue 的原始
  场景在四种模型条件下均为 36/36 且结果一致。升级后此前挂起的记录会自动重新仲裁。
- **播放方式判定**：改为按媒体库台账里的文件形态判定本地/网盘直链，不再用「是否已看到
  字节」倒推——上报先于取流到达是常态，此前会把刚开播的本地文件误标成网盘直链
- **实时圆点在任务视角也能亮**：此前只有停留在观看视角时才显示，从任务视角切过来或从侧栏
  深链进来都是灭的，真正需要提醒的场景全部失效
- **下载不再混入播放计数**：下载卡此前和播放会话同处「正在播放」分区，3 个在播 + 1 个在
  下载会显示成「正在播放 4」
- **会话身份稳定**：同一设备对同一集重复上报开始（seek、暂停恢复、换源重协商都会触发）
  不再重建会话，起始时间和已看位置不会在实时视图里闪回
- **体积/速度文本**：`99.997 MB` 此前会显示成 `100.00 MB`，撑破定宽数字列，现在正确回到
  `100 MB`
- 元信息行在设备名或客户端缺失时不再渲染出悬空的「·」分隔符
