## movieclaw v0.26.0

这一版给 Web 端加了**第二套皮肤**：设置 → 外观里多了「Netflix」主题，整档切换、
跟随账号、全设备同步——顶栏、底部标签栏、媒体库页顶的 Billboard、详情页构图全部
换一套语言，银玻璃原样保留在第一档。订阅侧则改掉了一个长期浪费流量的行为：
整季包只补一两集时，**包里已经有的文件不再重下**。

> ✅ **本版无需更新 Docker 镜像**：运行时依赖没有变化（runtime 仍为 16），
> 在「设置 → 更新与维护」里一键更新即可。

---

### 新功能

#### Netflix 主题：换的是整套外壳，不只是配色

「设置 → 外观 → 主题」里两张卡，点一下即时生效，选择存在账号上、换设备也跟着走。

- **桌面**：左侧玻璃侧栏换成 68px 顶栏（字标 + 电影 / 剧集 / 媒体库 / 我的订阅），
  页面顶端透明、滚下去渐变成实底黑；搜索、通知铃、账号菜单收在右上角，
  AI「新任务」是顶栏上的红色主操作。
- **移动端**：底部四页签（发现 / 媒体库 / 订阅 / 我的）取代抽屉侧栏，每一个都是
  真实路由——可刷新、可分享、前进后退可用。「我的」成为独立页面，设置是它的
  二级页（分区列表 → 分区内容，逐级返回）。
- **媒体库页顶的 Billboard**：接着看的那一集、或最近入库的那一部，全出血大图 +
  播放 / 更多信息 / 问 AI，画面从透明顶栏底下直接穿过。
- **详情页**：标题落在剧照左上，下滚时画面渐暗 + 模糊退场；桌面端剧照多于一张时
  会按序轮换。
- **全站跟着换**：圆角从 16px 压到 2/4/6 档、玻璃与背景大图整体停用（Netflix 是
  纯色平铺设计）、播放器强调色换成品牌红。刷新不会闪回银玻璃。

> 说明：本版的横向卡片行仍是竖版海报卡。Netflix 式的 16:9 横版卡与鼠标悬停展开
> 预览卡还在打磨，会在后续版本接上。

#### 整季包只补缺口集：包里已有的文件不再重下

以前只缺 S01E08、但资源只有整季包时，movieclaw 会把整季重新下一遍——既费流量，
也容易让重复版本混进库里。现在这类投递会以暂停态进下载器，把包里不需要的文件
标记为不下载，再恢复——只下你真正缺的那几集。洗版走的替代源同理。

判定很保守：**不确定就全量下载**。任何一集对不上文件、或文件解析不出确定的季集号，
都会放弃选择、老老实实整包下完——多下几个 GB 只是浪费，跳错文件会让任务永远卡住。
qBittorrent 与 Transmission 都支持。投递活动里会写明「跳过了包内多少个文件」。

#### 钉在首页的合集，在播放器里也是一个「媒体库」

用 Infuse / Jellyfin 客户端连过来时，钉了首页的合集会额外伪装成一个顶层媒体库，
和原来的合集身份并存。空合集与图片库合集不下发，成员只看得到自己有权限的内容。

### 改进

- **详情页背景改走高清原图**：进页面即刻预载并解码完成才显示，不再有「先糊后清」
  的换图过程；大屏上不再把 w1280 拉伸发虚。
- **横滚行的翻页箭头不会再莫名消失**：后台标签页等场景下浏览器会停帧，原先排进
  队列的测量永远不执行，箭头从此藏着不出来；改成帧停了也能兜底测量，并在行滚入
  视口时补测一次。
- **播放器窄屏可用性**：音轨 / 字幕 / 设置三个菜单在 375px 视口不再溢出屏幕右缘；
  字幕的「+ / −」微调键与开关在触屏上放大到好点的尺寸。
- **Windows 上能正常启动**：alembic 读配置固定按系统区域编码（中文系统是 GBK），
  撞上仓库里带中文注释的 UTF-8 配置会直接崩；另修了一处非 Linux 下的探测异常。
- 海报图加载完成改为淡入，不再「突然出现」；演员卡与预告片卡在横滚时误触不会再
  跳走。

### 修复

- **「我的」页与设置页在新设备上进不去**：主题判断先读的是本地缓存，新设备首次
  登录 / 无痕窗口 / 清过站点数据时缓存是空的，Netflix 用户点「我的」会被直接弹回
  媒体库，设置页则会跳过分区列表。现在会等账号偏好到账再决定去哪。
- **成员能看到管理员专属的 AI 入口**：Netflix 主题的顶栏与「我的」页漏了权限判断，
  成员点进去是一个后端全部拒绝的空页面。两处入口已按权限隐藏，手输地址也会挡回。
- **豆瓣条目详情页在手机上没有图**：页顶是一整块空白；TMDB 条目则把横版剧照拉伸
  裁成中间一条。现在手机端恢复了页内剧照横幅，与媒体库条目详情页同一套构图。
- **Netflix 主题手机详情页的剧照偏矮**：一条样式规则没生效，实际高度只有设计值的
  一半多一点。
- **「全部合集」入口可能整个消失**：它只长在媒体库页的「我的媒体库」那一行上，
  把那行隐藏掉、或者没有可见媒体库时，入口就没了——而那是唯一入口。现在会挪到
  页头。
- Netflix 主题下的头像渲染成了正圆（设计是圆角方形）；「仅银玻璃生效」的置灰设置
  项仍能用键盘操作并存盘。
- 首页字标偏大：桌面与手机各缩小一档，不再压住导航链接与页面标题。
